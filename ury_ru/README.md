# URY RU

Frappe-приложение — российская локализация и интеграции для URY.

## Модули

| Модуль | Назначение |
|--------|------------|
| `URY_RU_1C` | Обмен с 1С (номенклатура, остатки, цены, заказы) |
| `URY_RU_Fiscal` | Фискализация: АТОЛ, ШТРИХ-М, ОФД, 54-ФЗ |
| `URY_RU_Payments` | Эквайринг: Т-Банк, Сбер, СБП |
| `URY_RU_Delivery` | Агрегаторы: Яндекс Еда, Маркет Деливери |
| `URY_RU_Marking` | Маркировка: Честный знак |
| `URY_RU_EGAIS` | Алкогольный учёт: ЕГАИС |
| `URY_RU_Mercury` | Ветконтроль: Меркурий |

## Установка

```bash
bench get-app https://github.com/webzuweb/URY-RU --branch develop
bench --site <site> install-app ury_ru
```

## Разработка

Не менять файлы апстрима (`ury/`) без необходимости — всё новое в `ury_ru/`.
См. `ROADMAP.md` в корне репозитория.
